# Guide: Pushing Files One by One to GitHub

This guide explains how to push individual files from the `EPISENCE/frontend` directory to your GitHub repository.

## Step-by-Step Instructions

### 1. Open your terminal
Make sure you are in the root of your project (`HACKTHON`) or the `EPISENCE/frontend` directory.

### 2. Identify the file you want to push
Find the path to the file relative to the root of the Git repository.
For example: `EPISENCE/frontend/src/pages/HospitalDataPage.tsx`

### 3. Stage only that specific file
Use the `git add` command followed by the file path:
```bash
git add EPISENCE/frontend/src/pages/HospitalDataPage.tsx
```

### 4. Verify what is staged
Run `git status` to make sure only the file you wanted is under "Changes to be committed".
```bash
git status
```

### 5. Commit with a specific message
```bash
git commit -m "Updated HospitalDataPage.tsx"
```

### 6. Push to GitHub
```bash
git push origin master
```

---

## Repeat for the next file
You can repeat these steps for every file you want to push individually.

### Example for multiple files one by one:
```bash
# File 1
git add EPISENCE/frontend/src/App.tsx
git commit -m "Update App layout"
git push origin master

# File 2
git add EPISENCE/frontend/src/index.css
git commit -m "Update global styles"
git push origin master
```
